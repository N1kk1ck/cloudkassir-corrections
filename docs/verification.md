# Проверка версии 0.1 — 25.10.2026

Проверено локально на Windows:

- 33 автоматических теста: подготовка, CSV/XLSX и соответствие колонок,
  произвольные организации, дубли, суммы, возвраты, журнал, сбои и веб-интерфейс.
- Сценарий с семью произвольными организациями и совпадающими номерами заказов.
- Защита записи одного чека через два подключения к SQLite.
- Таймаут, ответ без ID и ошибка API не приводят к автоматическому повтору.
- Сборка wheel и установка в отдельную временную папку.
- Работа CLI, HTML-шаблона и CSS из установленного wheel.
- Демо: 2 готовых чека, 1 намеренное расхождение; API-запросов нет.
- Исключения Git для локальных конфигураций, входных данных, отчётов и баз;
  вымышленные примеры и пустые каталоги остаются доступны для коммита.

Все тесты отправки используют имитацию сервиса и запрещают реальную сеть.
Реальные чеки не отправлялись, рабочие API-статусы не запрашивались.

GitHub Actions настроен для Windows/Linux и Python 3.11–3.13. Удалённые
проверки ещё не запускались. Фискальные реквизиты и правомерность коррекции
проверяет пользователь; этот отчёт не подтверждает работу конкретной кассы.

и включение текста лицензии в пакет. Перед публичным выпуском остаётся
